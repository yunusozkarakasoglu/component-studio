## Bileşen Envanteri — Saf React Kütüphanesi

Aşağıdaki bileşenlerin tamamı **saf React**'tir — üçüncü parti UI bağımlılığı YOKTUR
(react + tailwind + kendi ikon seti `@/components/ui/icons` yeterlidir).
Kopyala → projene yapıştır → çalışır.

**Toplam: 4 bileşen (saf React)**

Her bileşen:
- Tek dosya, named export, interface dosya başında.
- `@id` + `@category` JSDoc etiketi dosya başında.
- Bağımsız import edilebilir, yan etkisiz.
- İkonlar kendi setimizden: `import { Search } from "@/components/ui/icons"`
