## Modern frontend arayüz dünyasının atomic design mantığıyla kategorize edilmiş ağaç yapısı

- Elements (Atoms)
  
  - Button, Input, Checkbox, Radio, Toggle
  - Label, Icon, Badge, Avatar, Tooltip

- Components (Molecules)
  
  - Form field, Search bar, Dropdown, Card
  - Modal, Toast, Breadcrumb, Pagination

- Layouts (Organisms)
  
  - Navbar, Sidebar, Header, Footer
  - Grid system, Container, Section

- Templates
  
  - Dashboard template, Auth template
  - Landing template, Settings template

- Pages
  
  - Home, Login/Register, Profile
  - Detail page, List/Table page, 404

- Design system
  
  - Tokens (renk, spacing, tipografi)
  - Theme (light/dark), Grid/breakpoints

- State & Data
  
  - Global state (Redux/Zustand), Server state (React Query)
  - Forms state, Routing state
